মুন্সী এগ্রো — অনলাইন পণ্য ক্যাটালগ, কার্ট, WhatsApp অর্ডার ও Admin মূল্য ব্যবস্থাপনা

এই প্যাকেজে:
- index.html: পাবলিক পণ্য ক্যাটালগ, ৫টি বিভাগ, সার্চ, ২৩টি পণ্যের SVG/ভেক্টর-স্টাইল চিত্র, কার্ট ও WhatsApp অর্ডার ফর্ম।
- dashboard.html: Admin-এর পণ্যের দাম/বিকল্পমূল্য পরিবর্তন, পণ্য দেখানো/লুকানো এবং নতুন পণ্য যোগ করার ব্যবস্থা।

GitHub Pages-এ যুক্ত করার নিয়ম:
1. বর্তমান index.html এবং dashboard.html-এর ব্যাকআপ রাখুন।
2. এই প্যাকেজ থেকে index.html এবং dashboard.html রিপোজিটরির মূল ফোল্ডারে Replace করুন।
3. interactive_farm_map.html, style.css, script.js, লোগো, ছবি ও অন্য বর্তমান ফাইল মুছবেন না।
4. Commit changes দিন, তারপর সাইটে Ctrl+F5 চাপুন।
5. Admin Login করে পণ্য ব্যবস্থাপনা খুলে দাম/বিকল্পমূল্য পরিবর্তন এবং সংরক্ষণ পরীক্ষা করুন।
6. পাবলিক পণ্য ক্যাটালগে দাম এসেছে কি না, কার্টের হিসাব ঠিক কি না, এবং WhatsApp অর্ডার খসড়া তৈরি হচ্ছে কি না পরীক্ষা করুন।

দাম ও একক:
পণ্যের প্রাথমিক দাম ব্যবহারকারীর দেওয়া তালিকা থেকে নেওয়া হয়েছে; বাজারদর স্বাধীনভাবে যাচাই করা হয়নি।

অর্ডার ব্যবস্থা সম্পর্কে:
কার্ট স্থানীয় ব্রাউজারে সংরক্ষিত হয়। অর্ডার বাটন WhatsApp-এ অর্ডারের খসড়া খোলে; WhatsApp-এ Send চাপতে হবে। এই সংস্করণে অনলাইন পেমেন্ট নেই এবং অর্ডার ওয়েবসাইটের ডেটাবেসে স্বয়ংক্রিয়ভাবে সংরক্ষণ হয় না।

Admin মূল্য পরিবর্তন সম্পর্কে:
Admin ড্যাশবোর্ডে পণ্যের মূল মূল্য এবং ডিম/লেবুর মতো একাধিক প্যাকের পৃথক দাম পরিবর্তন করা যায়। সেভের পর Firebase shared data দিয়ে পাবলিক ক্যাটালগ আপডেট হয়—যদি বিদ্যমান Firebase সংযোগ ও rules সঠিকভাবে কাজ করে। GitHub Pages-এ প্রকাশ করার পর লাইভে পরীক্ষা করুন।
