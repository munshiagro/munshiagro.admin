মুন্সী এগ্রো — Modern Green Corporate হোমপেজ আপডেট

এই ZIP-এ আছে:
- index.html — নতুন মোবাইল-ফ্রেন্ডলি Modern Green Corporate হোমপেজ
- README_modern_green_corporate.txt — প্রকাশ করার নির্দেশনা

এই সংস্করণে:
- উপরে Admin Login, Staff Login এবং Investor Login
- আধুনিক সবুজ/অফ-হোয়াইট ডিজাইন ও মোবাইল-ফ্রেন্ডলি লেআউট
- index.html-এর ভেতরে পাবলিক কৃষি ড্যাশবোর্ডের এমবেডেড ভিউ
- একই পেজের নিচে ক্লিকযোগ্য ফার্ম ম্যাপ
- লগইন হলে বিদ্যমান dashboard.html-এর ভূমিকা-ভিত্তিক ব্যবস্থাপনা UI-তে প্রবেশ

GitHub Pages-এ নিরাপদে আপডেট:
1. আপনার GitHub রিপোজিটরির বর্তমান index.html-এর ব্যাকআপ রাখুন।
2. এই ZIP Extract করুন।
3. শুধু নতুন index.html দিয়ে পুরোনো index.html Replace করুন।
4. dashboard.html, interactive_farm_map.html, style.css, script.js, Firebase config এবং সব ছবি/লোগো ফাইল অক্ষত রাখুন। সেগুলো আগে থেকেই কাজ করলে এই হোমপেজ আপডেটের জন্য সেগুলো replace করার দরকার নেই।
5. Commit changes করুন। প্রকাশ হলে ওয়েবসাইটে Ctrl+F5 দিয়ে রিফ্রেশ করুন।
6. Admin/Staff/Investor login, logout, public dashboard summary, map, mobile layout এবং Firebase sync বাস্তবে পরীক্ষা করুন।

নোট: নতুন HTML ফাইল তৈরি ও syntax-check করা হয়েছে; GitHub-এ Commit/Deploy করা হয়নি। Live authentication, authorization ও Firebase sync সরাসরি পরীক্ষা করা হয়নি। বাস্তব লগইন পরীক্ষা শেষ না হওয়া পর্যন্ত production-ready ধরে নেবেন না।
