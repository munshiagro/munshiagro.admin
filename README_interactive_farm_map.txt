মুন্সী এগ্রো — Interactive Farm Map ব্যবহারের নির্দেশনা

এই ফোল্ডারে থাকা ফাইল:
1. index.html — ওয়েবসাইটের হোমপেজের HTML ফাইল
2. interactive_farm_map.html — ক্লিকযোগ্য ডিজিটাল ফার্ম ম্যাপ
3. README_interactive_farm_map.txt — এই নির্দেশনা ফাইল

GitHub Pages-এ আপলোড করার নিয়ম:
1. ZIP ফাইলটি কম্পিউটারে Extract করুন।
2. আপনার GitHub রিপোজিটরির মূল ফোল্ডারে interactive_farm_map.html আপলোড করুন।
3. index.html-এ নতুন ম্যাপের লিংক যুক্ত করা থাকলে আপডেট করা index.html দিয়ে আগের index.html প্রতিস্থাপন করুন।
4. পরিবর্তন Commit করুন এবং GitHub Pages আপডেট হওয়া পর্যন্ত অপেক্ষা করুন।
5. ওয়েবসাইট খুলে Interactive Farm Map লিংকে ক্লিক করুন।

গুরুত্বপূর্ণ:
- README ফাইলটি শুধু নির্দেশনা পড়ার জন্য; ওয়েবসাইট চালাতে এটি আপলোড করা বাধ্যতামূলক নয়।
- index.html এবং interactive_farm_map.html একই রিপোজিটরি ফোল্ডারে রাখুন, যাতে ম্যাপের লিংক ঠিকভাবে কাজ করে।
- ম্যাপের নোট/তথ্য এই সংস্করণে ক্লাউডে সিঙ্ক হয় না; অন্য ডিভাইসে স্বয়ংক্রিয়ভাবে দেখা নাও যেতে পারে।
- জমির প্রকৃত নকশা অনুযায়ী জোন ও ফাঁকা অংশের অবস্থান পরে ঠিক করে নেওয়া উচিত।
