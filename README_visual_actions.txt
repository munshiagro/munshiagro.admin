মুন্সী এগ্রো — হোমপেজ ভিজ্যুয়াল আপডেট

প্যাকেজে আছে:
1) index.html — নতুন ভেক্টর-স্টাইল কৃষি চিত্র ও চারটি দ্রুত অ্যাকশনসহ আপডেটেড হোমপেজ
2) munshi-agro-integrated-farm.webp — হিরো সেকশনের চিত্র

GitHub Pages-এ আপডেট করার নিয়ম:
1. আপনার রিপোজিটরি munshiagro/munshiagro.admin খুলুন।
2. বর্তমান index.html-এর ব্যাকআপ ডাউনলোড করে রাখুন।
3. নতুন index.html এবং munshi-agro-integrated-farm.webp রিপোজিটরির একই মূল ফোল্ডারে আপলোড করুন।
4. পুরোনো index.html Replace করুন এবং Commit changes দিন।
5. dashboard.html, interactive_farm_map.html, style.css, script.js, Firebase-সংক্রান্ত ফাইল, লোগো ও profile.jpg পরিবর্তন/মুছবেন না।
6. লাইভ সাইটে Ctrl+F5 দিয়ে রিফ্রেশ করুন।

চারটি দ্রুত অপশন (প্রজেক্ট সম্পর্কে, ইনভেস্ট সম্পর্কে, প্রজেক্ট ভিডিও, ইনভেস্ট করুন) একই-origin dashboard.html-এর বিদ্যমান বাটন/মডাল চালু করে। তাই dashboard.html ফাইলটি একই ফোল্ডারে থাকতে হবে।
